# 商品內容整理規則

商品資料原本來自蝦皮賣場的批次匯出，那些文案是為賣場寫的，不能整段照搬到
自家網站。這份文件記錄「什麼資訊該放哪裡」與「什麼該刪掉」的判準，供日後
維護與再次匯入時遵循。

決策脈絡與尚未拍板的項目列在最後一節。

---

## 一、核心原則：規格優先，不補用途說明

會走到商品頁的人多半已經知道自己要什麼——照顧者、拿著出院衛教清單的家屬、
機構採購。他們打「灌食空針」進來，不需要有人解釋灌食空針是什麼，需要的是
**幾 ml、含不含接頭、幾支一盒、滅菌了沒**。

因此：

- **不要**為了「內文看起來太空」而硬補一句「本產品適用於……」的廢話
- 規格數字比形容詞重要，能進表格就不要留在散文裡
- 內文只保留放不進表格的東西：使用方式、注意事項、以及「這款和那款差在哪」

例外是配件類商品（壓脈帶接頭、抽痰機管路、變壓器、噴霧面罩）。這類買錯就是
白跑一趟，**「適用機型」比任何形容詞都重要**，務必填寫。

---

## 二、資料放哪裡

| 資訊種類 | 欄位 | 說明 |
|---|---|---|
| 固定屬性（材質、尺寸、數量、產地、滅菌狀態、適用機型…） | `specs` | 一個屬性一列，顯示為表格 |
| 可選規格與各自價格 | `variants` | 一列一個規格，價格區間由此自動推導 |
| 法定標示 | `regulatory` | 見第四節 |
| 使用方式、注意事項、款式差異 | 內文 | 放不進表格的才留這裡 |

### specs 的標籤不統一

商品規格的標籤**跟著商品走**，不做全站正規化。約束帶用「長／寬」、口罩用
「包裝規格」、變壓器用「適用機型」都是對的，硬統一反而失真。

### variants 與 specs 的關係

兩者都叫「規格」容易混淆，因此**前台只出現一張「商品規格」卡**，
`variants` 併進去（見第三節）。

---

## 三、商品頁版面

順序：**商品規格 → 商品說明 → 法定標示**。規格排在說明前面，因為那才是
訪客要找的東西。

### 商品規格卡的三種形態

**A. 可選規格全部同價**——不顯示價格欄，選項收成普通一列。價格上方已經寫過
一次，重複列出只是雜訊。

```
商品規格
────────────────────────
尺寸    M(單支)、L(單支)
長      27.5 cm
寬      17.5 cm
產地    台灣製造
```

**B. 可選規格不同價**——保留兩欄小表，排在固定屬性之前（那是購買決策），
中間以細線分隔，但仍在同一張卡內。

```
商品規格
────────────────────────
尺寸            價格
S            NT$799
M            NT$899
L            NT$999
────────────────────
材質    熱可塑性彈性體
直徑    S 15／M 20／L 24 公分
產地    日本
```

**C. 沒有可選規格**——就是單純的屬性表。

### 尺寸對照的寫法

S/M/L 各自的尺寸數值**併成一列**（如上例的「直徑 S 15／M 20／L 24 公分」），
不要拆成六列，也不要塞進規格標籤裡。

## 四、法定標示（`regulatory`）

前台與後台都顯示為「**法定標示**」。不要叫「醫療器材標示」——147 項上架商品
裡有 3 項是藥品（乙類成藥的 75% 酒精與乾洗手），拿的是藥品許可證而非醫療器材
許可證，另有 46 項根本不是管制品。

### 收錄哪些項目

商品層級、每項不同的五項，標籤統一：

```
許可證字號    衛部醫器製壹字第005369號
許可證品名    "昭惠" 治療用陰道灌洗器 (未滅菌)
持證藥商      昭惠實業股份有限公司
製造廠        昭惠實業股份有限公司嘉義廠
製造廠地址    嘉義縣朴子市大鄉里大槺榔179之52號
```

底下由產生器自動附上一行「消費者使用前應詳閱產品說明書。」——這句原本被逐字
打在 60 個商品的內文裡，改為統一輸出，內文不再重複。

**法定標示的標籤要統一**，這點與 specs 相反。因為蝦皮原始資料同一件事有多達
六種寫法（醫療器材許可證所載核准字號／醫療器材許可證核准字號／許可證核准字號
／醫療器材許可證字號/登錄字號／醫療器材許可證字號／許可證字號），不統一的話
同一個網站會用不同名稱指同一件事。

### 不收錄

**店家自己的藥商資訊**——東光儀器有限公司、崇德路 677、679 號、
南市衛藥販字第 6221011898 號、諮詢專線。這四項在 104 個商品裡一字不差，
放進商品頁等於每頁掛一段相同內容（Google 視為 thin content）。
應在全站層級揭露一次。

**罐頭值欄位**——「產品製造日期：標示於包裝上」（105 項）與
「有效期間或保存期限：標示於包裝上」（107 項）。欄位存在但值是範本字，
沒有資訊量。

（欄位名不同的「製造日期」「保存期限」若有真值——如「5年」「依批號前五碼」
——那算商品規格，進 `specs`。）

### 非管制品留空

碗盤、牙刷、保健食品等 46 項沒有許可證，欄位留空即可，前台不會顯示這個區塊。
不要為了填滿而編造。

## 五、內文要刪掉什麼

### 一律刪除

**蝦皮平台與物流說明**——7-11／全家／萊爾富／超商／宅配／出貨／運費／
「一單最多」／「一張單限下一件」／網拍／下標／聊聊／私訊／賣場／評價／面交／
退換貨猶豫期。我們不出貨也不在站上收單，這些是錯的資訊。

**政府查詢連結區塊**——「相關查詢連結」「※設立許可證明文件」「查詢連結：」
以及整段 FDA 網址與查詢路徑教學。許可證字號已在法定標示裡，要查的人自己會查。

**關鍵字標籤**——行尾或整行的 `#透明手套 #染髮` 這類蝦皮搜尋標籤。注意行首的
`#` 若不清除，會被產生器誤判為 Markdown 標題。

**重複貼三遍的同一句話**——賣家常把警語或提醒連貼數次。

**過期或固定日期**——如「製造日期：2012/06/01」。放在網站上會讓人以為是十幾年
前的庫存，改成「詳見包裝標示」或直接刪除。

**排版殘骸**——`:-材質` 這種殘留冒號、`*****規格尺寸*****` 星號裝飾、
`規　　格` 異常空白、`子母行內徑`（應為「型」）之類的錯字。

### 不動

**行銷語氣**——即使是蝦皮風格的用語也保留原文，不改寫。

## 六、匯入方法論（重要）

**一律以蝦皮原始 xlsx 為輸入，一次算到位。**

不要對已清洗的結果再套一輪清洗規則。那樣做有兩個問題：誤刪的內容救不回來，
而且前一輪規則的副作用會變成下一輪的輸入（例如砍掉關鍵字標籤後留下的孤兒
`Ranca` 一行）。

匯入腳本是 `scripts/import_shopee.py`，可重複執行、支援 `--dry-run`：

```
python3 scripts/import_shopee.py --sales <銷售資訊.xlsx> \
                                 --media <媒體資訊.xlsx> \
                                 --basic <基本資訊.xlsx> [--dry-run]
```

三份檔案的匯出方式：賣家中心 → 商品 → 批次工具 → 批次更新 → 選類別 → 下載。

| 匯出類別 | 提供什麼 |
|---|---|
| 銷售資訊 | 每個規格一列，含價格 → `price` / `variants` |
| 媒體資訊 | 每個商品一列，含規格名稱與圖片網址 → `variant_label` |
| 基本資訊 | 每個商品一列，含商品描述 → 內文與 `regulatory` |

比對只靠 `shopee_url` 裡的商品 ID 對匯出檔的商品 ID，**不做名稱模糊比對**。
147 項上架商品目前全數精準對上。

### 寫入 frontmatter 的兩個地雷

產生器的 frontmatter 解析器（`build_catalog.py` 的 `parse_frontmatter`）：

1. 值裡的「空白＋`#`」之後會被當成註解截斷
2. 引號必須成對

匯入腳本的 `yaml_value()` 已處理這兩者。多行文字（如 `regulatory`）使用 YAML
區塊字串 `|`，解析器支援。

### 內文的 Markdown 限制

`md_to_html()` 對 `#` 開頭的區塊**只輸出標題、同段其餘內容會被整段丟棄**。
因此把「產品規格：」這類段落標題轉成 `### 產品規格` 時，**必須前後補空行**讓
標題自成一個區塊，否則後面的規格會整段消失。

## 七、蝦皮連結開關

`build_catalog.py` 的 `SHOPEE_ENABLED`。設為 `False` 時全站不出現任何蝦皮
連結（頁首資訊列、頁尾社群圖示、商品頁下單按鈕、前端搜尋結果卡片），商品卡片
的「線上可購」標記也一併隱藏——站上沒有可下單的去處時，那個標記等於誤導。

商品的 `shopee_url` 資料不受影響，改回 `True` 即全部回復。

## 八、待決事項

以下尚未拍板，動手前需確認：

- **一頁描述多個商品的 8 項**——`misc-3` 與 `misc-26`（兩支聽診器互相包含）、
  `misc-29`（一頁四種止血鉗）、`supplies-54`（克司博／醫強／派頓三個品牌）
  等。選項為：各自拆開只留自己那一項、合併成一頁用規格表呈現差異、或維持
  現狀。待逐項討論。
- **法定標示的五個項目**是否就是最終清單（要不要加原產地、主要成分）。
- **店家藥商資訊放哪**——頁尾每頁都有，或獨立一頁再從頁尾連過去。
- **內文為空的 5 項**——`misc-23`、`supplies-11`、`supplies-50`、`supplies-89`、
  `supplies-91`，蝦皮上本來就沒有描述，需要人工補規格。
